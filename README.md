## 人声（心语/语音）的全部基频

人类语音的频率结构如下：

┌─────────────────────────────────────────────────────────────────┐

│ 频段            │ 对应什么声音              │ AI是否依赖        │

├─────────────────────────────────────────────────────────────────┤

│ 80-300Hz        │ 声带基频 F0               │ ✅ 高度依赖       │

│                 │ 男声 ~100Hz               │ 识别说话人身份    │

│                 │ 女声 ~200Hz               │                   │

├─────────────────────────────────────────────────────────────────┤

│ 300-800Hz       │ 第一共振峰 F1             │ ✅ 高度依赖       │

│                 │ 决定元音音色(a/e/i/o/u)   │ 语音转文字核心    │

├─────────────────────────────────────────────────────────────────┤

│ 800-3000Hz      │ 第二/第三共振峰 F2/F3     │ ✅ 依赖           │

│                 │ 辅音清晰度、个人音色       │                   │

├─────────────────────────────────────────────────────────────────┤

│ 3000-8000Hz     │ 高频辅音 /s/ /f/ /sh/     │ ⚠️ 部分依赖      │

└──────────────────────────────────────────────────────────

"心音"还可以指字面意思——心脏跳动的声音：

    心音成分	频率范围	说明
    S1（第一心音）	20-150Hz	二尖瓣/三尖瓣关闭，低频"咚"
    S2（第二心音）	50-300Hz	主动脉/肺动脉瓣关闭，稍高频"哒"
    S3（第三心音）	20-70Hz	儿童常见，低频
    心杂音	50-800Hz	瓣膜异常的高频啸叫
    1-800Hz 完整覆盖了全部心音频率。
